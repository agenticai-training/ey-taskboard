# Guides

**EY Engineering Task Board** — internal training material.

These guides are for engineers who need a procedure, not a product overview. Follow the numbered steps in order. Official Microsoft and Cursor documentation is linked where a screen or policy can change.

| Guide | Use when |
| --- | --- |
| [Connect Azure Boards to Cursor](azure-boards-cursor-mcp.md) | You need an Azure account, an Azure DevOps organisation and project, work items on Boards, and the Azure DevOps MCP server in Cursor |

## Document conventions

- Product names use the vendor spelling: Microsoft Azure, Azure DevOps, Azure Boards, Cursor.
- Placeholders appear in braces, for example `{YourOrganization}`. Replace them; do not commit real tokens.
- Do not store Personal Access Tokens, client secrets, or GitHub PATs in `.cursor/mcp.json` or any committed file.
